# WECR Regional Confederations Cup assets

The 10 Regional Cup trophy PNGs and the Western Europe competition logo were provided by MMD31 in the ChatGPT project.

- `docs/wecr-trophies/` includes 10 separately cropped original trophy images.
- `docs/wecr-logos/western_europe_logo.png` is the competition poster adapted to 1024 × 768 px.
- `MMD31_Trophy_Ireland_Wales.png` covers the Irish and Welsh Regions Cup (Ireland, Northern Ireland and Wales).
- `MMD31_Trophy_Germany.png` is used for the German Regions Cup and its existing test clone.
- Assets are used in the JSON as HTTPS raw GitHub URLs, with the original competition stage data unchanged.
